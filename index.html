Tentang Sistem Pakar

Sistem ini dirancang menggunakan metode logika Fuzzy Mamdani untuk melakukan deteksi tingkat risiko obesitas berdasarkan dataset secara otomatis dan akurat.

Sistem bekerja dengan memanfaatkan 4 variabel input dasar yaitu Usia, Jenis Kelamin, Tinggi Badan, dan Berat Badan. Sistem akan mengevaluasi kombinasi variabel ini menggunakan 30 rules Fuzzy (dibedakan untuk Laki-laki dan Perempuan) untuk menentukan tingkat risiko obesitas tanpa mengandalkan perhitungan IMT eksplisit.

Petunjuk Penggunaan:
  • Gunakan menu Demo Sistem untuk menguji diagnosis satu pasien secara manual dan melihat tahapan rincian perhitungan matematis Fuzzy secara transparan.
  • Gunakan menu Upload File untuk memproses dataset (file CSV) dalam jumlah masif secara otomatis. Sistem akan melampirkan hasil prediksi akhir ke dalam dataset tersebut.

Rumus Centroid:
Z* = ∫ z · μ(z) dz  /  ∫ μ(z) dz
Z* = ΣM / ΣA
